Privacy

QueueTime is a student project built at OxHack 2026. It measures one queue, the hackathon food point, and says when it is worth joining. This page lists everything it collects and where that goes.

What the sensor records

  • Counts: people crossing an entry beam and an exit beam, and presses of a hand-count button.
  • One distance reading per second from an ultrasonic sensor (how far down the queue it can see).
  • The time of each reading.

None of this identifies anyone. It is stored in a file on the team's laptop (data/live/run.csv).

The camera

If the camera is running, the laptop counts how many people stand inside the queue area. Only that number and the time are saved. Frames are never written to disk or sent anywhere, and nobody is recognised or tracked.

This website and the phone app

  • No accounts, no cookies, no analytics, no advertising.
  • If you set a reminder, its time is stored in your own browser (local storage) and nowhere else. Cancel it, or clear your browser data, to remove it.
  • The laptop serving these pages sees your device's local network address while you are connected, as any web server does. It does not log it.

Services outside the laptop

  • Fonts load from Google Fonts, so Google receives your IP address when a page opens.
  • When a Gemini API key is set, the queue numbers (counts, waits and forecasts, never anything about you) are sent to Google's Gemini model to word the recommendation.
  • If the voice alert is on, its sentences are sent to ElevenLabs to be spoken. They contain queue numbers only.

How long data is kept

Sensor and camera counts are kept for the length of the event to check the forecast against what happened, then deleted. Recordings used in the demo replay contain the same counts and nothing more.
